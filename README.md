# Agent架构师试炼——通关AI Agent

## 关于本资料

这是一份系统化的 **Agent 架构师实战训练材料**。覆盖从基础概念到生产部署的全链路知识体系。

## 特点

- **48 章核心内容**，覆盖 Agent 架构师必备知识
- **AI辅助润色**，保留技术干货与架构设计
- **章节独立为 HTML 文件**，方便离线阅读与分享
- **难度渐进**：基础篇 → 核心篇 → 进阶篇 → 综合篇
